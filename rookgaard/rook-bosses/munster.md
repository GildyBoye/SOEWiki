# Munster

Munster is the easiest boss in Rookgaard. It spawns randomly (tipically only 1 per day)

* Prerequisites: None
* Health: 1,958
* Experience: 1,935

#### Directions <a href="#directions" id="directions"></a>

#### Strategies <a href="#strategies" id="strategies"></a>

Treat it like a Diabolic Rat, at lvl 15+ you should be able to kill Munster easily

#### Loot <a href="#loot" id="loot"></a>

Munster always drops Gold Coin. Rare drops include Dice. Boots of Strong Haste only drop from its raid version (see below). Full loot table below.

</details>

#### Raid Version <a href="#raid_version" id="raid_version"></a>

When Munster spawns from a raid, it can also drop:

* Boots Of Haste
* Boots Of Strong Haste
* Gem Box
* Giant Amethyst
* Giant Topaz
* Gold Ingot
* Ring Of Souls
